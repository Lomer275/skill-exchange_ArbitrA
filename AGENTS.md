## Контекст проекта

Внутренняя библиотека скиллов Claude Code команды ArbitrA. Раздаётся двумя путями:
как Claude Code marketplace (`/plugin install team-skills@skill-exchange`) и как CLI
для установки одного скилла (`python cli/skill_exchange.py install <имя>`).

Python, без внешних зависимостей в рантайме. Точка входа — `cli/skill_exchange.py`
(подкоманды `list`, `install`, `uninstall`, `config`, `new`, `update`, `validate`,
`setup-hooks`); индексация и валидация — `cli/indexer.py`; конфиг — `cli/config.py`.

Сами скиллы лежат в `plugins/team-skills/skills/<имя>/` и состоят как минимум из
`SKILL.md`, `meta.json` и `README.md`; рядом могут лежать `references/`, скрипты
и данные — они тоже часть скилла и устанавливаются вместе с ним.

## Как запускать тесты

```bash
python -m pytest -q
```

Конфигурация — `pytest.ini`, зависимости — `requirements-dev.txt`.

## Проектные запреты

- **`README.md` и `plugins/team-skills/skills/index.json` не редактировать руками** —
  они генерируются хуком `hooks/pre-commit`. Правка руками будет затёрта.
- Не менять чужие скиллы без просьбы автора: у каждого в `meta.json` есть владелец.
- Не класть в скиллы секреты, IP и персональные пути — репозиторий раздаётся команде.
