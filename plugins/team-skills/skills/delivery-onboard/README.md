# Подключение проекта

Подключает проект к платформе доставки: цели, CI, схема и охранный хук.

## Использование

Вызовите `/team-skills:delivery-onboard`: «Подключи этот проект к платформе доставки.»

Источник конкретных настроек — `.delivery/project.yaml` проекта и
`delivery/targets.yaml` закреплённой платформы. При отсутствии доступа навык
останавливается. Внешние действия требуют соответствующего поручения.

Результат проверяется по фактическим выводам, записям проверок и журналу;
успешный запуск сам по себе не доказывает приёмку. Инструкция — в [SKILL.md](SKILL.md).

## Установка

Через CLI обменника: `python cli/skill_exchange.py install delivery-onboard`.
В составе установленного плагина навык доступен как `/team-skills:delivery-onboard`.
При личной установке через CLI — как `/delivery-onboard`.

## Автор

team

## Приоритет навыка

Если у проекта или пользователя есть собственный `/delivery-onboard`, он имеет приоритет.
Этот вариант используется при явном вызове `/team-skills:delivery-onboard` или отсутствии собственного навыка.
