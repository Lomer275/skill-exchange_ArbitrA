# close

Завершает сессию: сохраняет проверенный контекст и статусы по профилю .claude/team-skills.json, собирает повторы, готовит коммит и убирает временные файлы. Коммит и push — только с отдельным явным согласием на файлы и действие. Парный к /intro.

Фазы: отсечка пустой сессии → харвест повторов → контекст и статусы по факту → оценка исполнителей по правилам проекта (если они заданы) → предложение коммита и уборка.

Профиль задаёт `handoff`, `changelog`, `docs.tasks`, `docs.specifications`, `docs.unsorted`. Команда из `commands.push`, а при отсутствии ключа — `/team-skills:safe-push`; это умолчание не отменяет обязательный профиль документов. Без файла или нужного ключа навык останавливается и называет недостающее поле.

Перед коммитом показывает список файлов и сообщение. Согласие на коммит не разрешает push. Без человека в чате результат — `ready to commit`. Полное закрытие задачи выполняет `/accept`. Реестр кандидатов и бэклог используются только там, где их определил проект.

Собственный одноимённый навык проекта или пользователя имеет приоритет. Для явного выбора версии каталога используйте `/team-skills:close`.
