# close

Завершение рабочей сессии одной командой. Парный к `/intro`: утром агент читает хендофф и продолжает с той же точки.

**Пять фаз:** отсечка пустых сессий → харвест повторов в навыки (компаундинг) → контекст и актуализация статусов → карточка эффективности ярусов AI → коммит + уборка + отчёт.

**Источник:** портируемый навык из кокпита Алексея (передан команде 27.07.2026). Эта версия адаптирована под конвенции SUP — маркеры `[АДАПТИРУЙ]` заменены на реальные дома документов:

| Маркер оригинала | Чем заменён в SUP |
|---|---|
| `docs/handoffs/HANDOFF-<дата>.md` | существующий `SUP-HANDOFF.md` (текущее состояние; история — в `SUP-CHANGELOG.md`) |
| абстрактный таск-трекер | `docs/3. SUP-tasks/T*.md` + таблицы в спеках; полное закрытие — через `/accept` |
| реестр кандидатов | `docs/backlog/skill_candidates.md` |
| автокоммит дня | **предложение** коммита — правило проекта «коммитить только по явной просьбе владельца» |

Берёшь в свой проект — пройдись по этим четырём точкам и подставь свои пути.

**Фаза 3 добавлена относительно оригинала:** карточка соблюдения режима «Claude думает — Codex программирует» — сколько правок ушло Codex'у, сколько Claude сделал сам и по какому пункту кармана исключений. Правки без основания = нарушение режима.
