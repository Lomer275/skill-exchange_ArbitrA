# agents-context

Раскладывает общий контекст команды по обоим агентам сразу — Claude Code и Codex.

## Зачем

У обоих агентов одинаковое устройство настроек: глобальный файл с инструкциями плюс
файл в проекте. На большинстве машин **оба глобальных слота пустые**, поэтому агент,
открытый в проекте без своего `CLAUDE.md`, не знает ни правил команды, ни стоп-линий,
ни того, что рядом работает второй агент.

Скилл заполняет эти слоты, добавляет проекту `AGENTS.md` и описывает сам проект.

## Установка

```bash
python cli/skill_exchange.py install agents-context
```

Или через маркетплейс — тогда скилл доступен как `/team-skills:agents-context`.

## Использование

```
/agents-context
```

Дальше он делает всё сам: раскладывает контекст, читает репозиторий и заполняет
описание проекта.

## Путь без токенов

Настройка нужна чаще всего в тот момент, когда лимит Claude кончился и вы переходите
на Codex. Поэтому вся механика лежит в обычном shell-скрипте и модель ей не нужна:

```bash
~/.claude/skills/agents-context/agents-context.sh apply
```

Одна эта команда даёт рабочий контекст обоим агентам. Скилл сверху добавляет только
описание проекта.

Ещё две команды:

```bash
agents-context.sh check --all        # найти расхождения, ничего не менять
agents-context.sh link-worktrees     # выдать существующим worktree скиллы проекта
```

## Что он трогает и чего не трогает

| Файл | Что делает |
|---|---|
| `~/.claude/CLAUDE.md` | вставляет блок политики между маркерами |
| `$CODEX_HOME/AGENTS.md` | тот же блок, тот же текст |
| `<проект>/AGENTS.md` | блок + заготовка под проектные факты снаружи него |
| `<проект>/CLAUDE.md` | создаёт каркас, только если файла нет. Существующий **не трогает** |

Правится **только** содержимое между `<!-- BEGIN team-context -->` и
`<!-- END team-context -->`. Всё, что вы написали вокруг, переживает любое число
перезапусков. Файл без маркеров получает блок дописыванием — первый запуск не может
ничего разрушить.

Секреты скилл не трогает вовсе.

## Если что-то пошло не так

- **«маркеры повреждены»** — в файле остался один маркер из пары. Скрипт намеренно
  ничего не пишет: почините руками и запустите снова.
- **«Codex не найден»** — не ошибка, просто он здесь не установлен.
- Откатить блок — удалить его вместе с маркерами. Больше скилл ничего не добавляет.

## Правила команды

Текст политики лежит в `policy.md` рядом. Он **общий**: правка меняет правила у всех,
кто обновится. Своё личное дописывайте в `~/.claude/CLAUDE.md` **снаружи** блока —
там оно в безопасности.
