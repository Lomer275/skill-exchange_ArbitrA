# Подготовка изменения

Готовит изменение и намерение, разбирает доказательства проверки платформы.

## Использование

Вызовите `/team-skills:delivery-change`: «Подготовь изменение и дождись проверки платформы.»

Источник конкретных настроек — `.delivery/project.yaml` проекта и
`delivery/targets.yaml` закреплённой платформы. При отсутствии доступа навык
останавливается. Внешние действия требуют соответствующего поручения.

Результат проверяется по фактическим выводам, записям проверок и журналу;
успешный запуск сам по себе не доказывает приёмку. Инструкция — в [SKILL.md](SKILL.md).

## Намерение в PR

Заполните поля и сверьте их с парсером закреплённой платформы:

```markdown
## Намерение
Что: конкретное изменение
Зачем: ожидаемый результат
Решение: основание решения
Откат: команда и ограничения возврата
Проверка глазами: ссылка на стенд и результат просмотра для .js
```

## Установка

Через CLI обменника: `python cli/skill_exchange.py install delivery-change`.
В составе установленного плагина навык доступен как `/team-skills:delivery-change`.
При личной установке через CLI — как `/delivery-change`.

## Автор

team

## Приоритет навыка

Если у проекта или пользователя есть собственный `/delivery-change`, он имеет приоритет.
Этот вариант используется при явном вызове `/team-skills:delivery-change` или отсутствии собственного навыка.
