# dashboards

Принципы надёжных дашбордов: происхождение и свежесть чисел, пустые состояния, темы, доступ и владелец. Источники данных и сетевые ограничения определяются по документации текущего проекта; профиль необязателен.

Проверяет происхождение и свежесть данных, работу без JavaScript, отсутствие внешних CDN, обе темы, понятные единицы измерения, доступ до первого рендера и регистрацию в витрине с владельцем.

Перед проектированием определяет источники, права, хранение и достижимость из документации текущего проекта. Затем выбирает страницу в приложении или отдельный сервис. Карты инфраструктуры чужого окружения внутри нет. При наличии профиля использует `architecture` и `docs.guides`; без этих ключей пропускает соответствующий поиск с пометкой в отчёте.

Собственный одноимённый навык проекта или пользователя имеет приоритет. Для явного выбора версии каталога используйте `/team-skills:dashboards`.
