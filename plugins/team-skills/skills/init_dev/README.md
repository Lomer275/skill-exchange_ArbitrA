# Init Project Docs

Создаёт структуру документации, architecture, HANDOFF, CHANGELOG, CLAUDE.md и профиль .claude/team-skills.json по выбранному префиксу. Копирует гайды только при наличии источника.

## Когда использовать

См. полный `description` в [SKILL.md](SKILL.md) — там перечислены триггер-фразы и контекст активации.

## Что делает

См. [SKILL.md](SKILL.md) — алгоритм, формат вывода, правила.


Собственный одноимённый навык проекта или пользователя имеет приоритет. Для явного выбора версии каталога используйте `/team-skills:init_dev`.

Шаблон профиля: [templates/team-skills.json](templates/team-skills.json). При существующем профиле сохраняет его раскладку; отсутствующие гайды перечисляет в отчёте.
