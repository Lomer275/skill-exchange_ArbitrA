# Приёмка и восстановление

Проверяет выкат по журналу и хешам, ведёт откат и аварийные записи.

## Использование

Вызовите `/team-skills:delivery-release`: «Проверь результат выката и доказательства приёмки.»

Источник конкретных настроек — `.delivery/project.yaml` проекта и
`delivery/targets.yaml` закреплённой платформы. При отсутствии доступа навык
останавливается. Внешние действия требуют соответствующего поручения.

Результат проверяется по фактическим выводам, записям проверок и журналу;
успешный запуск сам по себе не доказывает приёмку. Инструкция — в [SKILL.md](SKILL.md).

## Установка

Через CLI обменника: `python cli/skill_exchange.py install delivery-release`.
В составе установленного плагина навык доступен как `/team-skills:delivery-release`.
При личной установке через CLI — как `/delivery-release`.

## Автор

team

## Приоритет навыка

Если у проекта или пользователя есть собственный `/delivery-release`, он имеет приоритет.
Этот вариант используется при явном вызове `/team-skills:delivery-release` или отсутствии собственного навыка.
