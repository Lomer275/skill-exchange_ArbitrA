# Accept Task

Закрывает задачу в документации по обязательному профилю .claude/team-skills.json: статусы в задаче, спеке и хендоффе, запись в журнале, перенос в настроенный каталог завершённых задач. Без коммита и push.

## Когда использовать

См. полный `description` в [SKILL.md](SKILL.md) — там перечислены триггер-фразы и контекст активации.

## Что делает

См. [SKILL.md](SKILL.md) — алгоритм, формат вывода, правила.


Собственный одноимённый навык проекта или пользователя имеет приоритет. Для явного выбора версии каталога используйте `/team-skills:accept`.

Без профиля или необходимых ключей выполнение останавливается. Формат: [профиль проекта](../../../../docs/team-skills-profile.md); создать его помогает `/team-skills:init_dev`.
