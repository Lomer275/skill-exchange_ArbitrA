# Spec Writer

Создаёт спецификации (S), задачи (T) и бизнес-требования (BR) по обязательному профилю .claude/team-skills.json и гайдам проекта. Один вызов — один файл, только скелет.

## Когда использовать

См. полный `description` в [SKILL.md](SKILL.md) — там перечислены триггер-фразы и контекст активации.

## Что делает

См. [SKILL.md](SKILL.md) — алгоритм, формат вывода, правила.


Собственный одноимённый навык проекта или пользователя имеет приоритет. Для явного выбора версии каталога используйте `/team-skills:spec-writer`.

Без профиля или необходимых ключей выполнение останавливается. Формат: [профиль проекта](../../../../docs/team-skills-profile.md); создать его помогает `/team-skills:init_dev`.
