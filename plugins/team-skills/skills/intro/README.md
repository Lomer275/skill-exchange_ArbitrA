# intro

Возврат в контекст в начале сессии. Парный к `/close`.

Читает в порядке: хендофф (RESUME-PROMPT) → раздел «Не выпущено» в CHANGELOG → открытые задачи → `git status`/`git log` → реестр кандидатов в навыки. Выводит один экран: где остановились · следующий шаг · открытые блокеры · состояние репо.

**Ничего не меняет** — ни правок, ни коммитов, ни деплоев.

Расширен относительно пятистрочной версии из оригинальной поставки `/close`: добавлена сверка хендоффа с фактическим состоянием репозитория. Хендофф отстаёт от репо на N коммитов — навык говорит об этом прямо, а не выдаёт устаревшую картину за текущую.
