# Spec Brainstorm

Интерактивное со-создание новой SUP-спецификации (SNN_*.md) через структурированную беседу.

## Когда использовать

Когда у тебя сырая идея для новой спеки и хочется проверить через question-answer что она зрелая, прежде чем оформлять файл. См. полный `description` в [SKILL.md](SKILL.md) — там перечислены триггер-фразы.

## Что делает

См. [SKILL.md](SKILL.md) — 6 фаз (проблема → цель → архитектура → DoD → финализация → делегирование в `/spec-writer`).

## Чем отличается от spec-writer

| | spec-brainstorm | spec-writer |
|---|---|---|
| Mode | Интерактивный (AskUserQuestion) | Генеративный (по входному описанию) |
| Когда | Новая идея, нет структуры | Структура понятна, нужно оформить |
| Output | Финальный draft через делегирование | Файл по конвенциям |

Связка: brainstorm → собрал summary → передал в writer → файл готов в `docs/2. *-specifications/`.
