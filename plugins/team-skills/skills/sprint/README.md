# Sprint

Выполняет задачи спецификации волнами: реализация → тесты → review-loop → `ready to commit`. Требует `.claude/team-skills.json`: `handoff`, `docs.specifications`, `docs.tasks`. Команда коммита/пуша — `commands.push`, единственное умолчание — `/team-skills:safe-push`. Формат профиля: `team-skills:init_dev` и `docs/team-skills-profile.md` каталога. Поддерживает `--dry-run` и `--yes`.

Собственный навык `sprint` проекта или пользователя имеет приоритет; каталог используется при явном `/team-skills:sprint` или отсутствии собственного навыка.

В конце показывает файлы, результаты проверок и сообщение коммита. Коммит и пуш требуют отдельного явного «да» в этом чате на конкретные файлы и действие. `--yes`, cron, HANDOFF и кнопки TG этого согласия не заменяют. Без человека в чате останавливается на `ready to commit` и отправляет уведомление через `tg_notify.sh`, если канал настроен.

## Когда использовать

См. полный `description` в [SKILL.md](SKILL.md) — там перечислены триггер-фразы и контекст активации.
