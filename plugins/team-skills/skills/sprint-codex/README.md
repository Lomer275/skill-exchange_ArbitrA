# Sprint (Codex)

Параллельный спринт через Codex-воркеры в git worktree. Drop-in замена /sprint для волн ≥2 задач.

## Когда использовать

См. полный `description` в [SKILL.md](SKILL.md) — там перечислены триггер-фразы и контекст активации.

## Что делает

См. [SKILL.md](SKILL.md) — алгоритм, формат вывода, правила.


Явная модель Codex: аргументы → конфиг проекта → gpt-6-luna/medium. Собственный одноимённый навык имеет приоритет. Требует профиль проекта; коммиты, merge и очистка волны — только после подтверждения человека.
