# Сеть: что машина должна и чего не должна достигать

## Эталон лежит вне репозитория

Обменник публичный, поэтому адреса, реестр выданных доступов и имена командных хранилищ
не хранятся в нём. Файл определений — `~/.config/env-audit/network.json` (права 600)
на проверяемой машине; в репозитории есть только `envaudit/data/network.example.json`.

**Файла нет** — проверки «не должен достигать» пропускаются с
`skipped[reason=no_definitions]`. Это слепая зона, а не «в порядке».

Формат:

```json
{
  "version": "1",
  "should_reach": [
    {"name": "github", "host": "github.com", "port": 443},
    {"name": "portal", "host": "portal.example.org", "port": 443, "max_latency_ms": 300}
  ],
  "should_not_reach": [
    {"name": "prod", "host": "prod.example.org", "port": 22,
     "granted": ["owner"], "note": "доступ выдаётся персонально владельцем"}
  ]
}
```

`granted` — список тех, кому доступ выдан. Человек в списке — «доступ есть законно»,
не находка.

## Как меряется

- **Достижимость** — TCP-`connect` к уже разрешённому адресу, медиана нескольких попыток;
  время DNS отдельным полем. Таймаут или закрытый порт → `not_measured`, а не «недоступно».
- **Возможный доступ — только по локальным данным:** `~/.ssh/config` (`Host`,
  `IdentityFile`), `ssh -G`, записи `known_hosts` на адреса из списка, наличие ключей;
  ключ хоста — `ssh-keyscan` без аутентификации. Такой сигнал означает «доступ возможен,
  не подтверждён».
- **Вход по ssh и выполнение команд на удалённых машинах не выполняются никогда.**
  Ни для проверки, ни «только логи». Это стоп-линия, а не предпочтение.

## Находки

- Обязательный адрес недоступен — **medium** (агент не сможет работать: не поставятся
  пакеты, не пройдут вызовы API).
- К машине из списка «не должен» есть настроенный ключ **и** запись `known_hosts`,
  а человека нет в `granted` — **critical** «доступ возможен»; подтверждает человек.
  Формулировка в отчёте: «доступ возможен, не подтверждён» — вход не выполнялся.
- Задержка к порталу выше порога — info.

Чинится **инструкцией**: отозвать ключ, поправить `config`. Выполняет человек.
