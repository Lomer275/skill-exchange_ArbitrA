# impl

Точка входа режима **«Claude думает и решает — Codex программирует»**.

До появления этого навыка делегировать код можно было только внутри `/sprint-codex` (нужен файл задачи TNN) и `/codereview-dual` (там Codex — ревьюер). Обычная правка «поправь вот это» всегда оставалась у Claude. `/impl` закрывает дыру: делегируется **любая** правка.

**Пять шагов:** routing-проверки → **Claude думает** (найти код, выбрать подход, зафиксировать скоуп и DoD) → бриф → `codex-worker role=implementer` → **Claude ревьюит дифф** и гоняет тесты.

Ключевое — шаг «Claude думает». Отдать воркеру пересказ фразы пользователя вместо брифа значит заставить его проектировать самому; промах воркера в этом случае — дефект брифа, а не Codex'а.

**Карман исключений** (объявлять вслух, иначе режим превращается в догму): Codex недоступен · правка ≤3 строк в уже открытом файле · Codex дважды промахнулся · нужен диалог по ходу · пользователь сказал «сам».

- **Зависимость:** навык `codex-worker` (рантайм) + Codex CLI ≥ 0.143.0.
- **Установка связки целиком:** `docs/claude-codex-pairing.md` в этом репозитории.
